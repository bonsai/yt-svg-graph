# 01 · MIXUE

約2分の日本語解説動画。主役はSVGで描いたグラフとオリジナルの簡易イラストです。

## 素材
- `tts.json` — シーンごとのナレーション原稿
- `index.html` — 16:9 SVGアニメーションのプレビュー／描画元
- `divide-img.py` — HTMLをシーン単位の静止画に分割（Playwright使用）
- `mux.py` — シーン画像とTTS音声をFFmpegで動画化・結合

## Build
GitHub Actions から **Build video assets** を実行。成果物はArtifactsからダウンロードできます。自動アップロードはしません。

数値は報道時点や集計方法に差があるため概数として表示し、価格比較は同一商品同士の比較ではないことを画面内に注記します。ナレーション音声は仮の日本語音声です。
